# 角色平衡与模式验证

2026-10-19，当前四角色、15秒跑道版本。种子和原始对位汇总见 [balance-results.json](balance-results.json)。

## 机制调整

- 张雪峰从直线冲刺改为跑圈、减速伤害跑道、最多五层配速及冲线重击。补给给下次跑步两层起始配速；普通技能和必杀的跑道均持续15秒。伤害按同一施法者/同一受击者每24帧最多一次结算，重叠跑道不会逐段重复扣血。
- 凑企鹅补足坦度与攻击，缩小普通落石散布并提升落石效率；原有拾荒、丢石头、飞踢及必杀保留。
- 许家印缩小大范围爆发、调整空城计范围，保留负债标记与诱饵后撤。
- 天素罗以追踪泡泡、延时困人陷阱、消耗印记连爆构成循环；最多三层印记、陷阱最多困两人、每名受击者最多吃两次连锁。
- 单挑、团战独立校准生命/攻击倍率；乱斗使用团战参数，张雪峰另有乱斗生存补偿。

## 换边对战

每个角色对位使用60个种子32000～32059，并交换左右位置；单挑、同角色三人队各720场，共1440场，全部在180秒保护预算内结束。每名角色每种人数参与360场；不包含镜像。单挑为前排，三人测试按前/后/前排设置。这是固定阵容的模拟胜率，不代表任意站位和混合阵容的胜率。

| 角色 | 1v1胜率 | 3v3胜率 |
|---|---:|---:|
| 凑企鹅 | 53.1% | 49.2% |
| 许家印 | 48.6% | 52.8% |
| 张雪峰 | 46.1% | 56.4% |
| 天素罗 | 51.9% | 41.7% |

仍存在克制：单挑凑企鹅对天素罗胜率86.7%，但对许家印仅26.7%；张雪峰对天素罗为30%。三人队中张雪峰对凑企鹅占优，但对许家印和天素罗接近五五开。总体接近不等于每个对位均等。
