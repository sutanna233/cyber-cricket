# 录像解说

仅管理员导出录像时使用。实际游戏没有解说播音、字幕或模型请求。

## 使用

登录后摆好阵容，点击「导出录像」。导出页默认开启解说，预设为 MiniMax Token Plan，语言模型 `MiniMax-M3.1-Flash`，OpenAI 兼容地址 `https://api.minimax.cn/v1`。填写自己的模型密钥，也可以修改地址和模型来接入其他兼容服务。

配音使用 MiniMax Speech 2.8 HD，默认音色 `male-qn-qingse`、语速1.05，支持切换Turbo、修改音色ID和语速。配音接口、密钥可与语言模型分别配置；是否拥有相应模型与语音权限由供应商账户决定。界面中的“使用同一密钥”是显式选项，可以关闭后填写独立配音密钥。

点击“保存到本机浏览器”或勾选“记住本机配置和密钥”后导出，可将接口、模型、音色、语速及两套密钥保存在当前站点的localStorage；下次打开自动填充。取消勾选会移除保存副本，点击“清除已保存配置”还会清空当前密码输入框。默认不保存，存储不可用时仍可单次导出。服务器仅在本次生成的内存请求里使用密钥，不写入服务器配置、录像或回放JSON。

默认参数依据[MiniMax OpenAI兼容接口](https://platform.minimax.cn/docs/api-reference/text-openai-api)、[同步语音合成](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)和[Token Plan老用户说明](https://platform.minimax.cn/docs/m-plan/token-plan-notice)，核对日期2026-10-20。当前官方订阅文档同时使用M Plan名称，历史Token Plan仍支持M3.1 Flash；语言与配音密钥的权限不能凭名称推定。

关闭解说即可沿用普通有声录像，不会请求模型或配音服务。

录像格式可选MP4或WebM。浏览器支持时默认使用H.264/AAC直接录制MP4，无需服务器转码；不支持时明确显示并预选WebM。文件扩展名、下载说明和回放元数据按实际编码容器生成，MP4不经过WebM时长修补。所选编码能力在调用模型和配音前检查。

## 与画面同步

1. 服务端用同一阵容、站位、种子和引擎逐tick复盘，提取真实大招生效、打断、淘汰、残血与最终结果。60tick为1秒，分身不计作玩家淘汰，重复角色用实例编号区分。
2. 大模型根据带编号的事件生成自然中文口播。每条事件另带服务器核实的短事实 `statement`，明确实际施法者、被打断者、淘汰者与冠军；乱斗及重复角色读作“雷军5号”。模型在每句中保留一次 `{{event}}`，自由编写前后口语点评，服务器再用本条短事实还原。禁止在占位符外另写角色、技能或编号，防止把SU7、击杀对象或冠军换给其他角色。最终最多18句、每句56字，同时校验事件编号、时间顺序、去重和结局；自由点评的语气与语义仍取决于模型。
3. 逐句合成云端语音，读取WAV真实时长，安排不重叠的时间轴。过密且无法及时播出的普通点评让位，结局保留。所有语音预载、解码并复验时长后才开始录制，不在录制过程中等待网络生成。
4. 浏览器按同样种子重放，按事件时刻播放声音并绘制字幕。普通句不排长队，迟到的结局完整播放并顺延结束时间。最后核对终局tick和hash，不一致则报错，不导出错配视频。
5. 录入同一游戏主混音，保留音效、角色语音和背景音乐。解说单独使用2.5倍增益（较初版约提高8dB），播音期间音乐降至原来的20%、技能音效降至55%，结束后恢复，实际游戏音量不受影响。生成时关闭本地监听，结局配音完整播放后结束。

回放JSON保存实际采用的解说文字、事件时间、计划播音时间和实际播放时间，不含密钥、音频临时地址或AudioBuffer。

自由乱斗按个人提供存活人数、血量和冠军，不向模型提供出场A/B侧、队伍或两侧血量汇总。乱斗口播中的A/B方、左右阵营、队友等称呼会被拦截，团战仍保留阵营解说。阵营或角色事实校验失败时，共用一次自动纠正机会，仍不合格则停止任务，不调用配音；纠正与初次请求共用60秒超时和取消信号。旧任务与已导出的视频不会自动更新，需要重新生成解说并导出；更新后重启Node服务以加载新模块。

## 结算画面

原来结算面板由网页DOM绘制，而`canvas.captureStream()`只录画布，所以录像里缺少完整战报。导出页现在使用独立Canvas结算卡，含胜方/乱斗冠军、用时、评分、存活、MVP、角色伤害和击杀，字幕区域单独保留。重复角色的同侧数据明确标为合计。结算至少保留5秒，并等待结局解说播完；无需开启解说也能得到完整结算。

## 运行与验证

Node.js18+，无需新增依赖或本地语音引擎。模型与配音仅由服务器调用，生成、查询、音频下载、取消均要求管理员权限和任务归属校验；临时音频30分钟过期，完成或取消时清理。单个生成任务限制并发，调用支持取消与超时，供应商错误不回显原始响应或密钥。

本地定向检查覆盖战况提取、模型输出、云语音协议、服务权限、取消、时间轴、主音量混音、结局延尾、字幕和Canvas结算；检查脚本保留在ignored的`tools/_aicheck/`。云端协议使用本机HTTP替身验证，未使用用户密钥或调用收费模型；真实MiniMax账户的鉴权、额度及主观音质需要用户填写自己的密钥后确认。
